🚀 ONEX Panel

ONEX Panel یک پنل حرفه‌ای و مدرن برای مدیریت و راه‌اندازی سرویس‌های مبتنی بر V2Ray / Xray است که با تمرکز بر سرعت، پایداری، مدیریت آسان و تجربه کاربری بهتر توسعه داده شده است.

✨ ویژگی‌ها

- 🎛️ رابط کاربری مدرن و حرفه‌ای
- ⚡ مدیریت و ساخت کانفیگ‌های متنوع
- 🚀 تمرکز بر عملکرد، سرعت و پایداری سرویس‌ها
- 🔧 مدیریت ساده و سریع کانفیگ‌ها
- 📊 امکانات مدیریتی و کنترلی برای مدیریت بهتر سرویس
- 🛡️ پشتیبانی از پروتکل‌ها و ساختارهای مختلف Xray
- ☁️ قابلیت Deploy و اجرای پروژه روی Railway
- 🔄 توسعه و بروزرسانی مستمر پروژه

☁️ نصب روی Railway

یکی از روش‌های ساده برای راه‌اندازی ONEX Panel، استفاده از پلتفرم Railway است.

با Deploy کردن پروژه روی Railway می‌توانید بدون نیاز به مدیریت مستقیم یک سرور، پنل را در محیط ابری اجرا و مدیریت کنید.

مراحل کلی

1. پروژه را Fork کنید.
2. پروژه را به Railway متصل کنید.
3. یک سرویس جدید برای پروژه ایجاد کنید.
4. تنظیمات و متغیرهای محیطی موردنیاز را وارد کنید.
5. پروژه را Deploy کنید.
6. پس از اجرای موفق، از طریق آدرس ایجادشده وارد پنل شوید.

«⚠️ برای عملکرد صحیح، قبل از Deploy تنظیمات موردنیاز پروژه و متغیرهای محیطی را بررسی کنید.»
